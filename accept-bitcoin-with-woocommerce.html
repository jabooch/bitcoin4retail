Bitcoin + WooCommerce

WooCommerce gives merchants multiple real Bitcoin payment choices.

Both CoinGate and NOWPayments currently publish dedicated WooCommerce integrations, making WooCommerce one of the clearest places to compare Bitcoin processors on product fit rather than forcing one provider.

CoinGate

CoinGate says its WooCommerce plugin can be installed from the WooCommerce/WordPress environment, connects via API credentials, supports Bitcoin Lightning and can settle to supported fiat or crypto. Its WooCommerce page currently lists a 1% processed-payment fee.

NOWPayments

NOWPayments publishes a dedicated WooCommerce plugin and describes it as its fully supported plugin option for e-shops. Merchants configure a wallet, API key and IPN secret, then enable the gateway inside WooCommerce.

What should decide it

Do not choose based on affiliate payout. Compare checkout experience, Lightning requirements, settlement currency, conversion costs, geography, refund process and the merchant’s desired custody model.
